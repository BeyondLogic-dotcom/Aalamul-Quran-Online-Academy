# Aalamul Quran Online Academy

The website for **Aalamul Quran Online Academy**, which offers one-to-one online Quran classes for children and adults around the world.

> This website was designed and developed **free of charge as a charity project**, to help more people learn the Holy Quran.

## Features

- **Mobile-first, fully responsive** layout, tested from 320px phones up to wide desktops
- **Free-trial booking form** that opens WhatsApp or email with the student's details filled in (nothing is stored on the site)
- **Hadith slider** with authentic narrations in Arabic and English, with autoplay, swipe and keyboard controls
- **Islamic design language**: Arabic calligraphy, mihrab arches and eight-point star geometry in the academy's green and gold
- Sections for About, Mission & Vision, eight Courses, Why Choose Us, How to Join, the Founder, and Contact
- **Accessible**: keyboard navigation, screen-reader labels and reduced-motion support
- **Lightweight**: plain HTML, CSS and JavaScript, with no frameworks or build step

## Project structure

```
index.html            The whole site (single page)
assets/css/style.css  Styles, written mobile-first
assets/js/main.js     Menu, scroll effects, hadith slider, course slider, trial form
assets/img/           Logo, favicon and touch icon
```

## Run it locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.
